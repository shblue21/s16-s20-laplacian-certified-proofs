# Version 0.1.0 release candidate

This combined release presents separately checkable exact computer-assisted
nonexistence proofs for orders 16 and 20.

The publication revision:

- restores the order-20 complement-representative mapping;
- states every Stage-2 bound, including the derived (H_d) interval;
- separates the order-16 and order-20 graph-to-model lemmas;
- includes complete enumeration, order-16 and order-20 computational
  specifications as appendices;
- preserves both frozen certificate archives and their detached hashes;
- includes the hardened current order-20 wrapper, helper programs, canonical
  result and fresh replay transcripts;
- provides combined metadata, file-specific licenses, build instructions,
  literature-search records and a top-level manifest;
- distinguishes internal separately implemented checks from external
  independent replication.
- states the actual Bash build/replay requirement, removes the remaining
  LaTeX underfull-box warnings and unnecessary appendix page breaks, and adds
  explicit Zenodo mixed-license upload instructions.

The release does not include proof-compression research and does not claim the
all-order conjecture, external peer review, external institutional replication,
different-language verification or proof-assistant formalization.
